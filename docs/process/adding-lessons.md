# Adding and Updating Lessons

After each interactive session:

1. **Preserve structure** — `module-NN-slug/NN-lesson-slug.md`, front matter, one H1.
2. **Edit the lesson file** — concepts, runnable Java, complexity, production notes,
   misconceptions, interview summary.
3. **Cross-link** — link related lessons; do not duplicate full sections.
4. **Update navigation** — `mkdocs.yml` if the lesson is new.
5. **Update [PROGRESS.md](../../PROGRESS.md)** — only for material actually studied.
6. **Log corrections** — add entries to [mistakes-and-misconceptions](../mistakes-and-misconceptions/index.md).
7. **Do not modify** the Spark or DSA handbooks from this repo unless explicitly requested.
